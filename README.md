# ILACE — Beyond Placement

**AI and Digital Assessment** — a 90-minute workshop on designing the evidence, not just the score.

## Contents

| File | What it is |
|---|---|
| `index.html` | The presentation. 49 slides, self-contained apart from the `videos/` folder. |
| `videos/` | The three clips the deck plays. |
| `prompt.html` | The take-home assessment design prompt, with a copy button. |
| `qr.png` | QR code linking to the prompt. |

## Presenting

Open `index.html` in any browser.

| Key | Action |
|---|---|
| `←` `→` | Move through slides and their staged reveals |
| click | Spotlight a card or image |
| `+` | Enlarge any picture |
| `N` | Speaker notes |
| `G` | Slide grid — drag to reorder |
| `E` | Edit mode — add, duplicate, delete, save a copy |
| `W` | Draw on the slide |
| `T` | Session timer |
| `F` | Fullscreen |

Edits live in the browser only until you use **Save a copy**.
